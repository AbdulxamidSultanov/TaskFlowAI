TASKFLOW AI — ПРИМЕРЫ ВЫЗОВОВ API
=================================

Базовый URL для локальной разработки:
  http://localhost:3000

Cookie-сессия хранится в HttpOnly cookie `taskflow_session`.
Для curl используйте один и тот же cookie-jar: -c (сохранить) и -b (отправить).

Все ответы API имеют формат:
  {"data": ...}

Ошибки:
  {"error":{"code":"...","message":"...","details":...}}


0. ПЕРЕМЕННЫЕ ДЛЯ ПРИМЕРОВ
-------------------------

В терминале:

  export BASE_URL=http://localhost:3000
  export COOKIE_JAR=/tmp/taskflow-cookies.txt

  export WORKSPACE_ID=ws-taskflow-hq
  export DEPARTMENT_ID=dept-engineering
  export USER_ID=user-engineering-2
  export PROJECT_ID=project-engineering-1
  export TASK_ID=task-engineering-1
  export EVENT_ID=event-engineering-1
  export NOTIFICATION_ID=notification-engineering-1
  export AI_CONVERSATION_ID=ai-conversation-engineering
  export TAG_ID=tag-engineering

Демо-доступ:
  email:    demo@taskflow.ai
  password: Demo1234!

Сотрудники отделов:
  любой seeded email + Password123!
  например: aziz.karimov@taskflow.ai


1. HEALTH
---------

GET /api/health

  curl -s "$BASE_URL/api/health"


2. AUTH
-------

### Регистрация (создаёт пользователя, сессию и добавляет в первый workspace)

POST /api/auth/register

  curl -s -c "$COOKIE_JAR" \
    -H "content-type: application/json" \
    -d '{
      "name": "New Teammate",
      "email": "new.teammate@taskflow.ai",
      "password": "Password123!",
      "departmentId": "dept-design"
    }' \
    "$BASE_URL/api/auth/register"

### Вход

POST /api/auth/login

  curl -s -c "$COOKIE_JAR" \
    -H "content-type: application/json" \
    -d '{
      "email": "demo@taskflow.ai",
      "password": "Demo1234!"
    }' \
    "$BASE_URL/api/auth/login"

### Текущий пользователь + настройки + workspace-членства

GET /api/auth/me

  curl -s -b "$COOKIE_JAR" "$BASE_URL/api/auth/me"

### Выход

POST /api/auth/logout

  curl -s -b "$COOKIE_JAR" -X POST "$BASE_URL/api/auth/logout"

    -d '{

      "slug": "customer-success",
      "description": "Onboarding and customer health",

    }' \
    "$BASE_URL/api/departments"

### Обновить отдел

PATCH /api/departments/:id

  curl -s -b "$COOKIE_JAR" \
    -X PATCH \
    -H "content-type: application/json" \
    -d '{
      "description": "Platform, product engineering and infrastructure"

14. RTK QUERY — БЫСТРЫЕ ПРИМЕРЫ В КОМПОНЕНТЕ
--------------------------------------------

Импорт:

  import {
    useGetTasksQuery,
    useCreateTaskMutation,
    useGetMeQuery,
    useLoginMutation,
  } from "@/lib/redux/api";

Пример чтения:

  const {data, isLoading, isError, refetch} = useGetTasksQuery({
    workspaceId: "ws-taskflow-hq",
    pageSize: 20,
    status: "in_progress",
  });

  // data = {items: TaskListItem[], pagination: {...}}

Пример мутации:

  const [createTask, {isLoading}] = useCreateTaskMutation();

  await createTask({
    projectId: "project-engineering-1",
    title: "Новая задача",
    priority: "high",
    assigneeId: "user-engineering-2",
  }).unwrap();

Пример входа:

  const [login] = useLoginMutation();
  await login({email: "demo@taskflow.ai", password: "Demo1234!"}).unwrap();

Типы и endpoint-ы находятся в:
  src/lib/redux/api.ts
  src/lib/redux/types.ts

Cookie отправляется автоматически, потому что fetchBaseQuery настроен с
credentials: "include". JWT/token в headers не нужен.


15. ВАЖНО
---------

- PATCH и DELETE меняют/удаляют реальные данные. Для экспериментов лучше
  создать отдельную запись и использовать её id.
- API работает с текущей cookie-сессией. Если получили 401 — сначала выполните
  POST /api/auth/login и сохраните cookie через -c.
- Даты передаются в ISO 8601 с таймзоной, например:
  2026-10-26T09:00:00.000Z
- `pageSize` максимум 100.
- Полная документация: docs/backend.md
- Гайд для frontend-конфигурации: docs/api-guide.md
