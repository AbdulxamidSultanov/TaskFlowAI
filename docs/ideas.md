# Идеи по улучшению TaskFlowAI

Файл-накопитель. Идеи фиксируются как есть, без реализации, пока не поступит команда
объединить всё и сделать итоговый вывод.

## Формат записи

- Дата
- Идея (формулировка пользователя)
- Область: UX / AI / задачи / календарь / команда / производительность / другое
- Заметки: уточнения, контекст, связанные идеи

## Правила

- Ничего не удаляем и не переписываем без просьбы.
- Дубликаты и пересечения помечаем, а не выкидываем.
- По команде «объедини всё» — группировка, приоритизация и финальный план текстом.

### I-002 — Создание задач вручную или через ИИ с отдельным контейнером
- Дата: 2026-11-11
- Область: задачи / AI
- Идея: таски создаются с помощью ИИ или вручную. Когда создаёт ИИ — нужен отдельный контейнер,
  в котором будет не подтверждённая форма тасков. Пользователь, у которого есть привилегии
  изменять таски, может изменить в ней что-нибудь, после чего форма подтверждается решением
  пользователя.
- Заметки: —

### I-003 — Область видимости по привилегиям + дерево оргструктуры
- Дата: 2026-11-11
- Область: команда / права доступа / UI
- Идея: область видимости создаётся исходя из привилегий: для обычных работников своя область,
  для супервайзеров своя и т.д. Уровень ниже не видит то, что стоит выше. Каждого супервайзера
  нужно обозначить кружочками и протянуть прямую до круга, где будет его команда, которая тоже
  обозначается кружочками. При наведении выводится короткая информация о нём: «просрочено 11»,
  «выполнено 100», «нарушений 0» или что-то наподобие. При нажатии выводится общая информация.
  Всё это должно быть как корни: от директора до работника — как на фото 1.
